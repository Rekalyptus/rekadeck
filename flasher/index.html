Install Rekadeck firmware

This page installs the Rekadeck firmware on a SparkFun Thing Plus ESP32-S3 over USB.

This browser can't install firmware. Open this page in desktop Chrome or Edge. The installer only works on a page served over HTTPS or from localhost.

Before you start

  • Use desktop Chrome or Edge.
  • Connect the board with a USB-C cable that carries data. Some cables only charge.
  • A new board should be erased first, so tick "Erase device" when the installer asks. Either way the board forgets its Wi-Fi and its link to your account, and any reviews it hasn't synced may be lost.

Already have a Rekadeck?

You don't need this page. A Rekadeck that's set up updates itself over Wi-Fi. This page is for a new build, or to recover a board that won't start.

If the board doesn't show up

Hold the BOOT button, press and release RESET, then let go of BOOT. Click Install again and pick the port that appears.

After installing

Press RESET if the board doesn't restart by itself. It starts on the Wi-Fi setup screen, and from there you link it to your account.

The installer is ESP Web Tools.
